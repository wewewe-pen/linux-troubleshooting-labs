# Инцидент: разные роли требуют разных прав на одной directory

## Требование

Для `runtime/` роли были асимметричны:

```text
web → создавать и удалять файлы
dev → только проходить внутрь
```

Обычного «дать группе доступ» здесь было недостаточно.

## Модель доступа

```text
owner = web  → rwx
group = app  → --x
others       → ---
```

В результате dev, попадая в group class, мог пройти по известному пути, но не мог создавать или удалять directory entries.
