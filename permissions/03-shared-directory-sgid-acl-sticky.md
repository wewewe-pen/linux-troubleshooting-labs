# Инцидент: shared directory — SGID, Default ACL и Sticky bit

## Требование

Два users должны были:

- создавать файлы в общей directory;
- получать общую group для новых объектов;
- изменять новые файлы друг друга даже при `umask 027`;
- не удалять чужие файлы;
- не открывать содержимое outsider.

## Что не сработало с первого раза

Сначала был установлен sticky bit, но он не решал наследование group.

Затем появился SGID. Он обеспечил наследование общей group, но этого тоже оказалось недостаточно: при `umask 027` новый файл мог потерять group write.

## Рабочая модель

Здесь понадобились три разных механизма:

```text
SGID        → новые объекты наследуют group
Default ACL → новые объекты получают нужные permissions
Sticky bit  → ограничивает удаление/rename чужих directory entries
```

Это три разные задачи, и один механизм не заменяет другой.

## Отдельный нюанс

Sticky bit не запрещает изменение содержимого чужого файла, если permissions самого файла разрешают запись. Он работает на уровне удаления/rename entries в directory.
