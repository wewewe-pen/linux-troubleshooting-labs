# Инцидент: stale PID file

## Симптом

PID из `mailer.pid` не существовал, но mailer продолжал писать logs.

## Расследование

Лог показывал, что mailer реально жив, но работает под другим PID.

## Причина

PID file содержал устаревшее число.

## Исправление

Нашёл реальный process и исправил PID file.
